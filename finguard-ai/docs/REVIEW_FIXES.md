# PR #2 审查修复 / Review remediation

针对 [集中审查评论](https://github.com/kegxthy/kegxthy/pull/2#issuecomment-6252355375)。原评论未逐项标注 P0/P1；本轮优先处理其中四项发布阻断问题。以下是实现与验证结果，不代表审查者已经重新批准。

## 1. 鉴权边界（已修复）

- 删除 loopback/testclient/IP 免认证逻辑。工作区启动即要求 32–256 字符 ASCII 随机令牌，所有 API 验证 bearer，不依赖 `request.client.host`、Host、Forwarded 或 X-Forwarded-For。
- 缺少/短/空白/非 ASCII 令牌拒绝启动；运行中令牌配置被移除则 API 返回 503。错误 bearer 返回 401。
- 测试覆盖 IPv4/IPv6 loopback、代理本地上游、远端/测试客户端及伪造转发头。

## 2. 原文暴露、保留与公共预览（已修复）

- 创建、详情和确认响应统一走 `public_task`，从不返回完整提取原文；只暴露候选/已选数据的证据行。
- 完整提取原文仅保留到人工确认；确认、失败或中断后删除，启动时清理旧版终态任务的完整来源。
- `FINGUARD_MODE=public_demo` 是界面预览：禁止全部 API，不打开工作区数据库，不上传或处理财报。可信工作组模式仍共享令牌和历史，明确不是公共多租户用户认证。
- 默认创建后 24 小时 TTL，可设 1–168 小时；启动、API 访问和每分钟清理，更新不延长过期时间；执行中阶段结束后清理。候选上限 128，单引句 1500 字符，任务记录预算约 20 MB。
- SQLite secure_delete 与原生备份/清理命令；备份拒绝覆盖。备份和提供方记录需要独立保留策略，未声称物理介质/外部备份被删除。
- 回归测试验证未选中原文哨兵不进入响应、确认后存储中无完整来源、TTL 不被状态更新延长、过期清理、备份及公开预览不读数据库。

## 3. 数值上下文与重复值（已修复）

- 期间必须为真实有效的 `YYYY-MM-DD/YYYY-MM-DD` 报告起止区间；自由年份、非法日期及反向区间拒绝。
- 使用明确支持的 ISO 币种集合，规范为大写；不猜测 `$`、RMB 等歧义输入。
- 新增 `scope`，执行只接受合并口径 `consolidated`。`validated_context` 同时保护人工确认、calculate、screen、check_balance 及 Agent 入口；同字段重复、跨期间/币种/口径或母公司单体数据均在运算前拒绝。
- 允许合法的不同倍率，并由 Decimal 规范化后计算。余额检查不再通过 dict 静默覆盖重复字段。测试覆盖所有直接入口，重复数据不会触发模型调用。

## 4. 正确页面上的错误字段/数字（已加强；语义复核仍必需）

- 必填原文 `line_number`（从1起）与 `number_index`（该行数字从0起），quote 必须等于对应的一整行（去首尾空白）。
- 数字之前的行标签必须匹配该字段的受支持中英标签；所选数字 token 必须与 value 一致，忽略 XLSX 单元格坐标中的数字。不再接受大段页面 quote 加数字成员判断。
- 过长行不发送给模型，保留原始行号并给出遗漏限制；分块保持行号偏移。
- 回归覆盖同页/同数字/错误 Revenue 行、正确行错误列索引、跨行宽引句、XLSX 行、长行截断与行号。
- 这仍不是期间列、币种、倍率或模型解读语义的独立证明。人工确认继续强制，界面/API/文档说明只完成字面行锚定检查。不在用户文案声称语义已验证。
