# AI 商品标签生成

> 作品集方案草案。概要来自项目所有者提供的信息；以下详细方案、评估口径与演示为本次整理建议，不代表已上线能力或真实业绩。

## 业务目标
让商品上架信息成为可运营的数据。

## 建议工作流
商品字段 → 标签体系约束 → 候选标签 → 证据校验 → 人工确认 → 入库

## 产品决策
品类、属性与营销标签分层；缺失属性不补造；受限标签必须有字段证据。

## 评估设计
标签准确率、覆盖率、人工采纳率、拒绝原因分布。均待评估。

## 可运行演示
[作品集交互入口](https://kegxthy.github.io/kegxthy/portfolio/)，选择本项目并运行固定示例。此页面是纯前端展示，不接模型或业务系统。

## 合成示例
```text
输入：示例棉质短袖；材质=棉；颜色=白。
候选：品类/短袖；材质/棉；颜色/白。
拒绝：纯棉（缺少含量证据）；抗菌（缺少检测证据）。
当前为固定规则示例，不执行模型分类。
```

- 真实样本及评估口径；如有成果，提供对比基线、样本量和周期。
