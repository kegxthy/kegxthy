# AI 商品标签生成

独立求职作品 MVP，2026-10-18 新建。不是原公司项目上线或效果声明。

[打开本模块](https://kegxthy.github.io/kegxthy/lab/?project=tags) · [工作台源码和部署](../../agent-lab/README.md)

## 当前实现
已实现：JSON 商品输入、受控词表、明确字段证据、缺失/非法属性拒绝原因、人工确认后导出；可选 DeepSeek 审核说明。不是已上线自动打标系统。

## 产品目标
让商品上架信息成为可运营的数据。

## 建议业务流程
商品字段 → 标签体系约束 → 候选标签 → 证据校验 → 人工确认 → 入库

## 关键决策
品类、属性与营销标签分层；缺失属性不补造；受限标签必须有字段证据。

## 评估计划（尚无实测成果）
标签准确率、覆盖率、人工采纳率、拒绝原因分布。均待评估。

## 本人职责定位
独立作品集的产品经理：场景定义、需求拆解、业务流程、原型设计、验收口径与迭代规划。实现由 AI 辅助完成；尚未开展真实用户访谈、线上运营或 A/B 实验。

## 交付边界
仅用合成商品和财务示例。模型结果须人工审核。内部平台截图、名称、账户、订单、接口与规则不进入公开样例。真实后端需单独部署和设置环境变量，GitHub Pages 仅运行浏览器工具。
