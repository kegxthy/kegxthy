## 当前实现
已实现：6 条合成商品目录、规则或可选 DeepSeek 意图解析、品类/预算/偏好/库存硬过滤和无结果提示。未接真实商品库、向量库或在线实验。

## 产品目标
从关键词匹配到能解释的选购结果。

## 建议业务流程
自然语言需求 → 意图与条件 → 商品召回 → 条件校验 → 结果解释

## 关键决策
预算与库存等硬条件优先；解释只引用商品字段，缺失信息明确显示未知。

## 评估计划（尚无实测成果）
条件满足率、无结果率、搜索转化率、延迟；需控制实验验证效果。

## 本人职责定位
独立作品集的产品经理：场景定义、需求拆解、业务流程、原型设计、验收口径与迭代规划。实现由 AI 辅助完成；尚未开展真实用户访谈、线上运营或 A/B 实验。

## 交付边界
仅用合成商品和财务示例。模型结果须人工审核。内部平台截图、名称、账户、订单、接口与规则不进入公开样例。真实后端需单独部署和设置环境变量，GitHub Pages 仅运行浏览器工具。
