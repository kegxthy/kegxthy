# 电商 AI 搜索

> 作品集方案草案。概要来自项目所有者提供的信息；以下详细方案、评估口径与演示为本次整理建议，不代表已上线能力或真实业绩。

## 业务目标
从关键词匹配到能解释的选购结果。

## 建议工作流
自然语言需求 → 意图与条件 → 商品召回 → 条件校验 → 结果解释

## 产品决策
预算与库存等硬条件优先；解释只引用商品字段，缺失信息明确显示未知。

## 评估设计
条件满足率、无结果率、搜索转化率、延迟；需控制实验验证效果。

## 可运行演示
