# 企业财务风险预警 Agent

独立求职作品 MVP，2026-10-18 新建。不是原公司项目上线或效果声明。

[打开本模块](https://kegxthy.github.io/kegxthy/lab/?project=finance) · [工作台源码和部署](../../agent-lab/README.md)

## 当前实现
已实现：结构化文本输入、字段证据行号、确定性指标计算、演示规则预警和 JSON 导出。可选服务端 DeepSeek 解释。PDF 自动提取与自主规划尚未加入新工作台；原 FinGuard 独立代码仍保留。

## 产品目标
让财务数据走向可追溯的风险判断。

## 建议业务流程
上传报表 → 字段核验 → 指标计算 → 风险解释 → 人工复核

## 关键决策
计算与解释分离；缺失字段不推断，异常结果进入人工复核。

## 评估计划（尚无实测成果）
字段准确率、风险召回率、证据覆盖率、复核耗时。均为建议评估指标，暂无已核实结果。

## 本人职责定位
独立作品集的产品经理：场景定义、需求拆解、业务流程、原型设计、验收口径与迭代规划。实现由 AI 辅助完成；尚未开展真实用户访谈、线上运营或 A/B 实验。

## 交付边界
仅用合成商品和财务示例。模型结果须人工审核。内部平台截图、名称、账户、订单、接口与规则不进入公开样例。真实后端需单独部署和设置环境变量，GitHub Pages 仅运行浏览器工具。
