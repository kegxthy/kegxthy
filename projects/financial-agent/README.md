# 企业财务风险预警 Agent

> 作品集方案草案。概要来自项目所有者提供的信息；以下详细方案、评估口径与演示为本次整理建议，不代表已上线能力或真实业绩。

## 业务目标
让财务数据走向可追溯的风险判断。

## 建议工作流
上传报表 → 字段核验 → 指标计算 → 风险解释 → 人工复核

## 产品决策
计算与解释分离；缺失字段不推断，异常结果进入人工复核。

## 评估设计
字段准确率、风险召回率、证据覆盖率、复核耗时。均为建议评估指标，暂无已核实结果。

## 合成示例
```text
输入：示例企业流动资产 120，流动负债 100。
工具计算：流动比率 1.20。
证据：示例字段 current_assets / current_liabilities。
处理：单一指标不足以判断企业风险，需结合现金流与行业背景。
本演示为固定示例，不调用 DeepSeek。
```
