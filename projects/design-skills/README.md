# 截图驱动的产品设计 Skills

> 作品集方案草案。概要来自项目所有者提供的信息；以下详细方案、评估口径与演示为本次整理建议，不代表已上线能力或真实业绩。

## 业务目标
将页面设计经验沉淀为可复用的工作方法。

## 建议工作流
指定脱敏截图 → 观察与推断分离 → 设计规范草案 → 人工确认 → Skill → 原型验收

## 产品决策
只从可见页面提取模式；隐藏流程与业务规则列为待确认；使用虚构平台、数据和组件名。

## 评估设计
规范覆盖率、生成原型一致性、人工修改量、首次验收通过率。均待试验。

## 可运行演示
[作品集交互入口](https://kegxthy.github.io/kegxthy/portfolio/)，选择本项目并运行固定示例。此页面是纯前端展示，不接模型或业务系统。

公开示例使用虚构商城；不复用分期乐内部截图、账户、订单、接口、业务阈值或权限配置。用户提供的页面需先替换品牌、人物与业务数据；不能仅打码后直接视为可公开。截图只能支持可见的布局观察，隐藏流程必须另行确认。
