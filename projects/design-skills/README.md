# 截图驱动的产品设计 Skills

[打开本模块](https://kegxthy.github.io/kegxthy/lab/?project=skill) · [工作台源码和部署](../../agent-lab/README.md)

## 当前实现
已实现：脱敏页面文字事实转可下载 SKILL.md、截图本地预览、可选服务端视觉模型分析。未配置视觉模型时不处理截图；不推断隐含权限、状态机和接口。包含独立 Skill 示例。

## 产品目标
将页面设计经验沉淀为可复用的工作方法。

## 建议业务流程
指定脱敏截图 → 观察与推断分离 → 设计规范草案 → 人工确认 → Skill → 原型验收

## 关键决策
只从可见页面提取模式；隐藏流程与业务规则列为待确认；使用虚构平台、数据和组件名。

## 评估计划（尚无实测成果）
规范覆盖率、生成原型一致性、人工修改量、首次验收通过率。均待试验。

## 本人职责定位
独立作品集的产品经理：场景定义、需求拆解、业务流程、原型设计、验收口径与迭代规划。实现由 AI 辅助完成；尚未开展真实用户访谈、线上运营或 A/B 实验。

## 交付边界
仅用合成商品和财务示例。模型结果须人工审核。内部平台截图、名称、账户、订单、接口与规则不进入公开样例。真实后端需单独部署和设置环境变量，GitHub Pages 仅运行浏览器工具。
