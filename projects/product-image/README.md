# AI 商品图生产工作台

> 作品集方案草案。概要来自项目所有者提供的信息；以下详细方案、评估口径与演示为本次整理建议，不代表已上线能力或真实业绩。

## 业务目标
把商品素材处理变成可审核的生产流程。

## 建议工作流
原图输入 → 资产权限确认 → 白底 / 透底 / 多角度任务 → 一致性检查 → 审核

## 产品决策
白底与透底属于素材处理，多角度属于生成任务；保留商品形态与规格，生成结果须复核。

## 评估设计
可用图通过率、商品一致性、人工返工率、单张成本和耗时。均待真实样本验证。

## 可运行演示
[作品集交互入口](https://kegxthy.github.io/kegxthy/portfolio/)，选择本项目并运行固定示例。此页面是纯前端展示，不接模型或业务系统。
