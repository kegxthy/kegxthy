# AI 商品图生产工作台

独立求职作品 MVP，2026-10-18 新建。不是原公司项目上线或效果声明。

[打开本模块](https://kegxthy.github.io/kegxthy/lab/?project=image) · [工作台源码和部署](../../agent-lab/README.md)

## 当前实现
已实现：本地图片上传、手动百分比裁切、从边缘连通背景移除、白底/透底 PNG 下载。背景复杂或主体触边时需人工修正。不能自动修复叠在商品上的 Logo；多角度仅有任务导出，尚未接图像生成模型。

## 产品目标
把商品素材处理变成可审核的生产流程。

## 建议业务流程
原图输入 → 资产权限确认 → 白底 / 透底 / 多角度任务 → 一致性检查 → 审核

## 关键决策
白底与透底属于素材处理，多角度属于生成任务；保留商品形态与规格，生成结果须复核。

## 评估计划（尚无实测成果）
可用图通过率、商品一致性、人工返工率、单张成本和耗时。均待真实样本验证。

## 本人职责定位
独立作品集的产品经理：场景定义、需求拆解、业务流程、原型设计、验收口径与迭代规划。实现由 AI 辅助完成；尚未开展真实用户访谈、线上运营或 A/B 实验。

## 交付边界
仅用合成商品和财务示例。模型结果须人工审核。内部平台截图、名称、账户、订单、接口与规则不进入公开样例。真实后端需单独部署和设置环境变量，GitHub Pages 仅运行浏览器工具。
